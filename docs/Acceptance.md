# 分层验收清单（以 exact-SHA 记录及设备反馈为准）

## Apple 编译 / 产物

- tweak 和 Preferences 完整源图均经 Apple Swift 编译器通过；生产启动入口不依赖 Orion。
- 优化、dead-strip 后的生产入口由 dyld 自动执行；原方法恰好调用一次，挂载/移除及重复启动在 UIKit 测试替身上通过。测试替身不等于真实 SpringBoard/Hook 后端。
- arm64、arm64e 切片均符合对应越狱环境的 ABI；实际最低系统版本为 15.0。
- 设置入口 detail、bundle 的 NSPrincipalClass、Objective-C 运行时类名一致，真实 PSViewController 的 initForContentSize: 创建路径可用。
- 正确的 scheme、安装位置、Substrate/PreferenceLoader 依赖、无 Orion 链接、最终包内资源及哈希独立检查。
- 相同生产动作 harness 在旧 SHA 上失败、当前 SHA 上通过；使用系统类测试替身，不能据此宣称真实锁屏键效果已通过。

## 首批设备集中验收

1. 安装后开关默认关闭；不改变图标点击、主屏幕翻页和长按编辑。
2. 设置首页进入“主屏幕的手势”，只显示“启用主屏双击”和“选择双击动作”。动作页只显示带选中标记的“系统锁屏”，点击返回，不当场执行锁屏。升级前已保存的开关值不重置，修改后无需注销，退出设置再进入仍保留。
3. 已解锁竖屏主屏幕空白处单指双击，只调用一次系统锁屏键入口，设备锁定且灭屏，过渡与本机短按实体锁屏键一致；随后可正常唤醒/解锁。锁定状态、显示状态与过渡效果分别记录。
4. 分别点击/双击图标、文件夹、小组件、搜索控件、Dock：不锁屏且原操作正常。
5. App 内、锁屏、多任务、通知中心、控制中心、横屏：不误触发。
6. 翻页/拖动图标/长按编辑过程中不锁屏；结束后恢复正常。
7. 第一击后停用/离开桌面/锁屏/旋转/移走视图，不遗留一次迟发的锁屏请求。
8. 多次进入桌面及一次注销后没有重复识别或重复调用，偏好值持久保存。
9. VoiceOver 开启时本项目不干扰其双击交互；关闭后可恢复。
10. 必需私有类/selector/签名不符合时，拒绝功能，不造成 SpringBoard 退出。

设计下限 iOS 15.0，不设硬编码版本上限；分别记录实际测试的 iOS 版本及 Rootless/RootHide 布局。未测项保留待验证，不从某一个系统/布局推及其他版本。

状态区分：**源码检查 → 实际 Swift runtime 测试 → Apple 双目标编译 → 包内验证 → 真机通过**，互不替代。
